# M2AMDI
Bienvenue sur notre projet de "Pokédex", basé sur l'univers de Pokémon.
Dans l'univers de Pokémon, le Pokédex est un bestiaire des différentes espèces des créatures peuplant l'univers de Pokémon. Ces créatures portent également ce nom. 
Dans l'histoire du jeu, le Pokédex a été inventé par le Professeur Chen dans le but de mieux les comprendre. 
C'est donc un outil qui repertorie diverses informations sur le Pokémon étudié : nom, description, taille, sexe, localisation...
Notre projet permet d'explorer l'ensemble des Pokémons connus.
